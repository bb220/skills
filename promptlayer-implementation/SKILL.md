PromptLayer is the most popular platform for prompt management, collaboration, and evaluation.

## Quick Start
Begin with the quickstart guide in the /references directory to understand how to get started with the python SDK. Every other document describes features supported by the SDK, which you can refer to as needed. The documents includes code snippets and examples to help you get started.

## Resources in the /references directory
- **quickstart.md**: A quickstart guide on implementing the Python SDK.
- **supported-methods.md**: An overview of all methods supported by the SDK, including both synchronous and asynchronous versions.
- **run.md**: A reference for using the `run()` method, the recommended way to execute prompts and log them in one step.
- **custom-logging.md**: A reference for using logging methods separately from execution.
- **error-handling.md**: A reference for handling common errors and scenarios.
- **async-support.md**: A reference for using the asynchronous versions of the SDK methods.
