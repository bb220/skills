# AuthKit Implementation
AuthKit is a platform provided by WorkOS that simplifies the implementation of authentication in applications. It provides a set of tools and APIs to handle various authentication methods.

## Quick Start
Begin with the quickstart guide in the /references directory to understand how to implement it using the python SDK. Every other document is a part of the API reference, which you can refer to as needed. The documents includes code snippets and examples to help you get started.
